# Thu Muc Luu Tru Du Lieu Tham Chieu Phan Loai Nghe Si

Thu muc nay chua cac file du lieu tham chieu (vi du: .csv) phuc vu viec phan loai nghe si Viet Nam va quoc te.

## Dinh dang file khuyen nghi:
- Ten file: `artists_classification.csv` (hoac bat ky file `.csv` nao)
- Ma hoa: UTF-8
- Cac cot pho bien duoc ho tro tu dong:
  - `artist` hoac `artist_name` hoac `name`: Ten nghe si
  - `country` (vi du: 'VN', 'Vietnam', 'Foreign') hoac `is_vietnamese` (1/0, True/False) hoac `type` ('vietnam', 'international')
